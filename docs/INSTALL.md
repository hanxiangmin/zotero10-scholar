# 安装与使用

版本：3.1.2，适用 Zotero 10.0.x。本地开发版尚未发布。

## 安装

在 **工具 → 插件 → 从文件安装插件** 中选择 `zotero10-scholar-3.1.2.xpi`，不要解压。
与 3.0.x、3.1.x 使用相同插件 ID，可直接升级。个人版 `*-personal.xpi` 包含本地指标表，勿公开分发。
公开版在 **工具 → Scholar Rank 设置** 中导入有权使用的 CCF、JCR、CAS JSON；[格式说明](DATA_FORMAT.md)。
文献列表列标题右键 → 更多列 → 勾选“索书号”。安装或导入数据本身不会修改整库文献。

## 三个操作

选中文献，右键 **Scholar Rank**；设置页中的三个按钮使用主窗口当前选中的文献。

1. **整理元数据**：直接运行已启用的规则。标题只整理空白，保留大小写、基因名、专业缩写和富文本；页码及卷期只处理明确的格式。语言只保守补全中英文空值，缩写只按本地表补空值。可选择在手动整理结果中提示疑似重复数量，不自动合并。
2. **根据 DOI 更新**：只手动触发，调用 Zotero 原生 DOI 查询。返回的题目、作者、期刊、日期、卷期页码、ISSN、网址、摘要等非空字段直接覆盖现值，不再弹出覆盖确认。未返回的字段保留；整条作者列表有效时才替换作者。只接受 DOI 一致且条目类型一致的唯一结果。
3. **更新分区指标**：直接用当前数据表替换索书号，无需另外选择覆盖；没有匹配数据时不清空已有值。

DOI 更新只向查询服务发送所选条目的 DOI，不上传附件、全文、笔记或整个文献库。它不改条目类型、标签、附件、笔记、Extra 和索书号，不创建重复文献；若需要重算指标，再执行第三项。服务返回信息可能不完整，请自行核对。

不再提供备份/恢复入口，也不生成任何新的 Extra 状态。旧版留下的 Extra 内容保持原样，不再作为更新锁定条件，不自动删除。错误操作可使用 Zotero 自带的撤销/重做；关闭后不能依赖本插件做长期恢复。
正在查询时条目被其他操作修改、变为只读或插件停用，会跳过写入。保存失败时当前事务回滚。

## 自动处理

两个开关分别为 **新增条目时自动整理元数据** 和 **新增条目时自动更新分区指标**，即时保存，默认关闭。
两者都开启时先整理再匹配指标；仅处理新增期刊/会议文献，不处理编辑已有条目的每次变化。
自动分区更新仅填空索书号，已有值需要手动执行“更新分区指标”。**没有自动 DOI 联网更新开关**。

## 指标显示与数据

显示顺序为 CCF、年度 JIF、JCR 分区、中科院大类分区/TOP。缺失部分直接省略，实际 `0` 和 `<0.1` 保留。
例如 `C|—|—|—` 更新后显示 `C`；`—|3.6|Q1|3区` 更新后显示 `3.6|Q1|3区`。
会议不套用期刊 IF/JCR/CAS；Workshops、Findings 等不借用主会议等级。

中科院数据只接受 2025 升级版大类分区，不接受新锐 XR、小类或其他年份替代。
JCR 年份和来源在设置中查看；年份以已导入数据为准，不会联网自动更新年度表。导入时禁止用较早 JCR 覆盖已加载的新年份。
3.1.2 不再保存每条文献的指标历史年份，因此手动更新前请核对当前数据版本。

## 与 Linter for Zotero / Format Metadata 共存

[Linter for Zotero](https://github.com/northword/zotero-format-metadata) 的“清理被滥用的标准字段”规则可能把索书号中的期刊指标清空。
请在其设置中关闭这条规则；如已启用本插件自动整理，也请停用重复的自动整理。
已有指标被清空后，选中条目执行 **更新分区指标** 即可。Scholar Rank 不修改其他插件设置，也不在后台反复重写来对抗其他插件。

本项目未配置在线更新服务器，升级请手动安装 XPI；默认 `.invalid` 更新地址不影响功能。
