# 安装与使用

版本：3.1.0。适用 Zotero 10.0.x。

本版为本地开发版，安装 `dist/zotero10-scholar-3.1.0.xpi`；含你本地指标数据的版本为 `dist/zotero10-scholar-3.1.0-personal.xpi`。

## 安装

1. 如仍启用原 Zotero 7 Scholar Rank 插件，先停用，避免同时写索书号。本项目 3.0.x 可直接升级，无需卸载。
2. 打开“工具 → 插件”，从齿轮菜单选择“从文件安装插件”，选择 `zotero10-scholar-3.1.0.xpi`。不要解压 XPI。
3. 公开版不附带第三方指标表；打开“工具 → Scholar Rank 设置与数据版本”，依次导入你有权使用的 CCF、JCR、CAS JSON。
4. 在文献列表的列标题上右键 → 更多列 → 勾选“索书号”。
5. 选中几条熟悉的论文 → 右键 **Scholar Rank → 预览指标与数据来源**。
6. 确认后选择“更新所选条目（保护已有索书号）”。原 Zotero 7 插件写入、且没有本项目备份的旧值，需要另选“覆盖旧索书号（先备份）”并确认。

安装和导入数据不会自动批量修改文献库。数据准备见 [数据说明](../data/README.md)。
个人构建 `*-personal.xpi` 已包含本地数据时可省去第 3 步；不要将这种含数据构建公开分发。

## 显示规则与升级

顺序为 `CCF | 年度 JIF | JCR 分区 | 中科院大类分区及 TOP`，只显示有数据的指标：

| 原格式 | 当前格式 |
| --- | --- |
| `C|—|—|—` | `C` |
| `—|3.6|Q1|3区` | `3.6|Q1|3区` |
| `A|20.4|Q1|1区TOP` | `A|20.4|Q1|1区TOP` |

实际影响因子 `0`、`<0.1` 保留，不作为缺失项处理。没有指标的新条目不写入。
旧字符串存储在文献字段中；升级后选中条目，执行一次“更新所选条目”才会采用新格式。
缺少原指标所需的数据包时，会保留旧结果并提示导入，不会把暂未加载数据当作指标消失。
加载的 JCR 数据早于条目已保存的指标年时也会跳过，避免升级到公开版后发生年份回退。

## 备份和恢复

首次写入前的索书号保存在 Extra 的 `Zotero Scholar Rank:` 行中；请保留这行。
右键“恢复原索书号”可跨重启恢复，且在没有指标数据包时仍可使用。
支持 Zotero 原生撤销/重做。手动改过的结果、损坏或重复的备份行都会阻止自动覆盖。
原插件早已覆盖且未备份的真实索书号无法凭空恢复。卸载不会自动还原字段，请先恢复再卸载。

## 更新与限制

当前 CAS 数据格式只接受 2025 升级版大类分区，不接受新锐 XR、小类分区或其他年份替代。
JCR 年份以数据包注明的发布年和指标年为准。查询是离线的，不会自动更新到未来年度。
默认不自动填充新条目；如需要，可在设置页开启。

## 与 Linter for Zotero / Format Metadata 共存

[Linter for Zotero（Format Metadata）](https://github.com/northword/zotero-format-metadata) 3.3.2
默认在新增条目后运行“清理被滥用的标准字段”。该规则把 `callNumber`（索书号）中的部分期刊指标
视为字段滥用，会清空以数字影响因子开头或以 `X区` 结尾的值并再次保存条目。因此可能看到
`3.6|Q1|3区`、`20.4|Q1|1区TOP` 等内容先出现、随后消失；单独的 `C` 等未命中其规则的值则可能保留。
Scholar Rank 3.1.0 已把新增条目的自动写入排在这项自动清理之后；但以后手动执行完整 Lint 时，
该规则仍会再次清空索书号，所以下面的设置才是长期共存方式。

共存设置：

1. 重新启用 Linter for Zotero / Format Metadata。
2. 打开该插件的设置，找到“条目级规则”。
3. 只取消 **“清理被滥用的标准字段”**。
4. “添加条目时自动执行 Lint”和其余需要的格式化规则可以继续启用。

无需停用整个插件。Scholar Rank 不会自动修改另一个插件的设置，也不会在后台无限重写索书号来对抗清理规则。
如果关闭该规则后旧条目的索书号已经为空，选中条目后执行一次
**Scholar Rank → 更新所选条目（保护已有索书号）** 即可重新生成。这个安全修复只在当前计算结果仍与
Extra 中记录的上次结果一致时执行；如果数据包或分区策略已经变化并提示“索书号被手动修改”，请改用
**覆盖旧索书号（先备份）** 并确认。已有 Scholar Rank 状态、后来又改成非空手工值的条目仍会跳过。

本项目未配置在线更新服务器。默认 `.invalid` 更新地址可能使“检查更新”提示连接失败，
不影响本地功能；升级请手动安装新 XPI。

## 元数据整理

右键 **Scholar Rank → 整理元数据与更新指标**：查看每个字段的前后值，勾选条目，再点击应用。
预览不会写入；应用时若条目内容、类型、文献库或写权限已变，会跳过该条目。
已有真实索书号和手改指标继续保留；元数据整理也可在没有指标数据包时独立使用。

设置中可逐项开关标题、DOI、页码、卷期、语言、期刊缩写规则。
自动整理默认关闭，与自动填充指标分别设置；自动模式不弹重复提示。
标题只整理无富文本标题的空白，不转换句子式大小写；短标题或其他语言不猜测语言代码。
期刊缩写表需另行导入，格式见[数据格式](DATA_FORMAT.md#journal-abbreviations)。

右键 **恢复整理前的元数据** 可预览恢复；被手动修改的字段跳过，其他字段仍可恢复。
恢复不会自动刷新索书号；如果恢复了用于匹配的期刊缩写，请再更新指标。
原值存储在 Extra 的 `Zotero Scholar Metadata:` 行中，请保留；指标仍使用独立的 `Zotero Scholar Rank:` 行。

右键 **检查重复条目** 检查同一库内的期刊与会议，可点击按钮在主窗口选中疑似重复项。
DOI 相同或足够长的规范化标题相同会提示；两个非空 DOI 不同时不只凭标题判断。
这不是完整的全文/作者/版本去重算法，结果需人工核对。
