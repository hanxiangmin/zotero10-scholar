# 安装与使用

版本：3.2.0，适用 Zotero 10.0.x。[已发布安装包](https://github.com/hanxiangmin/zotero10-scholar/releases/latest)。

## 安装

在 **工具 → 插件 → 从文件安装插件** 中选择 `zotero10-scholar-3.2.0.xpi`，不要解压。
与 3.0.x、3.1.x 使用相同插件 ID，可直接升级。只有一个安装包，内置 CCF、JCR、CAS 表，首次使用无需导入。
以后可在 **工具 → Scholar Rank 设置** 中导入有权使用的新 JSON；[格式说明](DATA_FORMAT.md)。此前导入的本机数据仍会加载，设置中可核对实际版本。
文献列表列标题右键 → 更多列 → 勾选“索书号”。安装或导入数据本身不会修改整库文献。

## 手动操作

选中文献，右键 **Scholar Rank**；设置页中的四个操作按钮使用主窗口当前选中的文献。

所有更新结束后都会显示结果窗口，逐条列出修改字段、修改前和修改后的完整内容；未变化、查询失败或跳过的数量另行说明。自动更新结果会追加到同一个窗口，窗口不阻塞后续导入。关闭结果窗口不撤销修改。

1. **整理元数据**：英文标题采用句首及冒号后首字母大写，保留 `ccRCC`、`fMRI`、模型名等专业写法；其他专名可在设置中补充，或选择保留原大小写。富文本不自动改写。页码及卷期处理明确的格式，语言和期刊缩写仅补空值。
2. **联网更新元数据**：优先调用 Zotero DOI 查询，并从 Crossref 补充日期证据。DOI 为空时，使用标题、作者、期刊/会议与年份检索 Crossref；规范化标题必须一致，作者与出版信息也要符合，只有一个可信候选才补上 DOI 并继续更新。缺少信息、多个候选、未收录或查询失败时保留原值。已有 DOI 查询失败或格式异常时不改用标题猜另一个 DOI。会议采用明确的会议年份；期刊采用正式卷期日期。Springer 会议章节有明确会议证据时也可用于更新会议论文，不改变库中条目类型。
3. **更新分区指标**：匹配成功后直接替换索书号。AAAI 等以期刊文章导入的会议录按完整名称匹配会议等级。名称与 ISSN 冲突、同简称但全称不符时不猜测。任何未匹配记录均保留原值，不清空已有指标。
4. **下载全文 PDF**：仅手动处理所选期刊/会议文献。已有 PDF / EPUB（包括尚未同步到本机的附件）直接跳过；只新增正文 PDF 子附件，不改标题、日期、分区或已有批注。结果窗口列出新增文件以及每篇未下载的原因。无 DOI 时只尝试条目中的论文网址；需要先补全 DOI 的，可先执行第二项。

附件下载不访问 Google 学术，不使用用户配置的自定义下载源。单文件最多 50 MB，串行请求间隔至少 1.5 秒；HTTP 401/403/429/503 或识别到登录、验证码页面时停止本批，不反复尝试其他入口。设置页可点击“停止下载”。下载成功的附件仍保留，未处理项可之后重新选中手动尝试。需要机构登录、浏览器脚本或补充材料的，请在出版社页面手动保存。误下载的新增附件可在 Zotero 中单独删除；本功能不提供批量撤销下载。

联网更新元数据时，有 DOI 则只向查询服务发送 DOI；无 DOI 的检索会向 Crossref 发送标题、第一作者、期刊/会议和年份。不上传附件、全文、摘要、笔记或整个文献库。元数据更新不改条目类型、标签、附件、笔记、Extra 和索书号，不创建重复文献；若需要重算指标，再执行第三项。服务返回信息可能不完整，请自行核对。

**会议名称标准化**默认随元数据整理启用：将“会议名称”和“会议论文集标题”统一为目录中的标准全称，例如 MICCAI 对应 `International Conference on Medical Image Computing and Computer-Assisted Intervention`，不追加 `MICCAI-2025`。自动整理、手动整理和 DOI 更新使用同一规则；日期独立处理，不从名称里的年份推断。未匹配、两个名称冲突或 Workshop 等附属会议不强行改名；设置中可以关闭该规则。分区指标操作本身仍只修改索书号。

不再提供备份/恢复入口，也不生成任何新的 Extra 状态。旧版留下的 Extra 内容保持原样，不再作为更新锁定条件，不自动删除。错误操作可使用 Zotero 自带的撤销/重做；关闭后不能依赖本插件做长期恢复。
正在查询时条目被其他操作修改、变为只读或插件停用，会跳过写入。保存失败时当前事务回滚。

## 自动处理

两个开关分别为 **新增条目时自动整理元数据** 和 **新增条目时自动更新分区指标**，即时保存，默认关闭。
两者都开启时先整理再匹配指标；仅处理新增期刊/会议文献，不处理编辑已有条目的每次变化。
自动分区更新仅填空索书号，已有值需要手动执行“更新分区指标”。**联网查询只在手动点击第二个操作后执行**。

## 指标显示与数据

显示顺序为 CCF、年度 JIF、JCR 分区、中科院大类分区/TOP。缺失部分直接省略，实际 `0` 和 `<0.1` 保留。
例如 `C|—|—|—` 更新后显示 `C`；`—|3.6|Q1|3区` 更新后显示 `3.6|Q1|3区`。
会议不套用期刊 IF/JCR/CAS；Workshops、Findings 等不借用主会议等级。

中科院数据只接受 2025 升级版大类分区，不接受新锐 XR、小类或其他年份替代。
JCR 年份和来源在设置中查看；年份以已导入数据为准，不会联网自动更新年度表。导入时禁止用较早 JCR 覆盖已加载的新年份。
3.1.2 不再保存每条文献的指标历史年份，因此手动更新前请核对当前数据版本。

## 与 Linter for Zotero / Format Metadata 共存

[Linter for Zotero](https://github.com/northword/zotero-format-metadata) 的“清理被滥用的标准字段”规则可能把索书号中的期刊指标清空。
请在其设置中关闭这条规则；如已启用本插件自动整理，也请停用重复的自动整理。
已有指标被清空后，选中条目执行 **更新分区指标** 即可。Scholar Rank 不修改其他插件设置，也不在后台反复重写来对抗其他插件。

本项目未配置在线更新服务器，升级请手动安装 XPI；默认 `.invalid` 更新地址不影响功能。
